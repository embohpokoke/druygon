# DruCode Design System

## Theme

"Mission control for kids": a focused light workspace paired with a deep-space profile rail. Robo anchors the child-facing experience.

## Color

- Violet `#6C4FD8`: primary navigation and identity
- Teal `#2EC9C0`: run and success actions
- Amber `#FFB930`: hints, rewards, and XP
- Navy `#23204F`: space background and strong text
- Light background `#F5F4FC`: application canvas
- Success `#328D64`, danger `#D75151`: semantic state only

## Typography

Use MiSans or a rounded system sans for interface text and a system monospace for code. Keep child-facing body copy readable, compact labels uppercase, and headings clearly separated by weight and scale.

## Components

Use pill action buttons, circular three-state lesson nodes, compact XP/status chips, large-radius white work surfaces, consistent focus rings, and subtle top-down shadows. The language control is a familiar two-option segmented switch.

## Layout

Desktop uses a profile rail plus learning canvas. Tablet stacks the rail above the canvas. Mobile converts the mission path to a vertical list and keeps primary actions full-width.

## Motion

Only communicate current state or action feedback. Respect reduced motion and avoid decorative page-load animation.
